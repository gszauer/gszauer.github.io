AI assisted coding for games

Dear reader, i have a confession to make.... I'm lazy. And honestly, a lot of code is boring to write. I know what you're thinking: But we live in the future! Sureley, ai can solve this problem right? Good question, i wonder about that myself. So, i did my best to incorporate some AI into my workflow, and ask it to generate some boring code for a hobby game engine i'm making. That's what this blog is about.
