Features

  • Catches JavaScript runtime errors
  • Captures console warnings, errors, and info messages
  • Handles unhandled promise rejections
  • Shows errors in a stack with oldest on top
  • Only the oldest error (top) times out and disappears after 3 seconds
  • Maximum of 100 errors in the queue
  • Smooth slide-in/slide-out animations
  • Color-coded by type (red for errors, orange for warnings, blue for info)
  • Shows timestamp and stack trace when available

Usage

Simply include this script at the top of your HTML page. It will automatically start capturing errors and displaying them in the overlay.

The error handler exposes a global ErrorHandler object with methods:

  • ErrorHandler.addError(message, type, stack) - Manually add an error
  • ErrorHandler.getQueueLength() - Get current queue length
  • ErrorHandler.clearAll() - Clear all errors
