--- CAVES

We're going to add a new type of tile, a cave. All caves have the same icon: 🪟. One cave appears every 3 floors, starting with floor 3. A cave is like a shop that has a specific requirement. If the requirement is not met, a modal popup is shown with what the player needs to do to enter. That modal just has a close button.
If the player does meet the criteria for what a cave needs, the cave dissapears and drops a durable item. If the player has every possible durable item, the cave drops 50 coins.

There will be the following types of caves:
    Greedy cave, only opens if the player has 50 coins or more
    Brave cave, only opens if the player has 20 health or more
    Strong cave, only opens if the player has 10 strength or more
    Mortal cave, opens as soon as an enemy dies (assuming the cave is revealed)
    Material cave, opens only when the user uses an item
