--- Challenge

We're going to add a new type of tile, a challenge. All challenges have the same icon: 🪟. One challenge appears every 3 floors, starting with floor 3. A challenge is like a barrel that has a specific requirement to break. If the requirement is not met, a modal popup is shown with what the player needs to do to break it or. That modal just has a close button.
If the player does meet the criteria for what a challenge needs, the challenge tile dissapears and drops a durable item. If the player has every possible durable item, the challenge drops 50 coins.

There will be the following types of caves:
    Greedy cave, only opens if the player has 50 coins or more
    Brave cave, only opens if the player has 20 health or more
    Strong cave, only opens if the player has 10 strength or more
    Mortal cave, opens as soon as an enemy dies (assuming the cave is revealed)
    Material cave, opens only when the user uses an item
